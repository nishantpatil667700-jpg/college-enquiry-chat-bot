1. Problem Statement

Admission offices and student desks receive repetitive queries regarding admissions, courses, fees, eligibility, and facilities. This project delivers an automated, grounded GenAI College Enquiry Chatbot using Python, Streamlit, and Groq LLM API. The system answers queries strictly from an official college knowledge sheet (college_info.txt), eliminating hallucinations and reducing manual administrative workload.

2. Tools & Model

  • Language & Framework: Python 3.12, Streamlit 1.67 (UI and session-based state management).
  • LLM & Provider: Groq API running llama-3.3-70b-versatile with low temperature (0.1) for strictly deterministic factual responses.
  • Knowledge Grounding: Flat-file knowledge base (college_info.txt) injected directly into the system prompt context.
  • Configuration: python-dotenv for secure API key loading without committing secrets to Git.

3. Step-by-Step Procedure

  1. Virtual Environment: Configured Python virtual environment (python3 -m venv .venv) and installed streamlit, groq, and python-dotenv.
  2. API Key Provisioning: Created a developer account on Groq Cloud, acquired a free API key, and configured local .env.
  3. Knowledge Base Construction: Drafted college_info.txt with verified details for Apex Institute of Engineering & Technology (AIET), covering programmes, seat matrix, CAP/institutional admissions, fees, scholarships, and campus facilities.
  4. Prompt Engineering & Grounding: Developed a strict system prompt instructing the LLM to answer solely from the provided text, enforce verbatim fallback when facts are missing, and politely reject non-college queries.
  5. Streamlit Application Development: Built app.py with st.chat_input, persistent session history, one-click FAQ test buttons, and an interactive sidebar configuration.
  6. Rigorous Testing: Evaluated 6 diverse prompts (valid FAQs, unlisted queries, and out-of-scope non-college queries).
  7. Packaging & Version Control: Maintained .gitignore, committed code to GitHub, and created Code.zip for Drive submission.

4. Prompt Design & Iterative Improvement

"You are a helpful and polite college enquiry assistant for Apex Institute of Engineering & Technology (AIET). Answer questions using ONLY the college information provided below. Do not use outside knowledge or speculate. If the answer cannot be found, reply EXACTLY: 'Sorry, this information is not available in the college information provided. Please contact the college admission office at admissions@aiet.edu.in or call +91 20 2765 4321.' If the user asks non-college questions, politely decline."

Improvement Made: The initial prompt permitted the model to extrapolate unlisted fees and answer general general-knowledge queries. Introducing explicit negative constraints ("Do not use outside knowledge"), a strict domain boundary, and an exact fallback sentence prevented hallucinations and guaranteed 100% factual accuracy.

6. Challenges & Solutions

  • Hallucinations on Unlisted Courses: Early tests showed the LLM assuming standard university policies when asked about missing details. Solution: Lowered temperature to 0.1 and enforced negative system prompt constraints with an explicit fallback message.
  • API Key Protection: Preventing credentials from accidental public Git upload. Solution: Secured keys in .env with strict .gitignore rules and implemented a fallback input field directly in the Streamlit sidebar.
  • Conversation Continuity: Preserving chat context across Streamlit's reactive re-renders. Solution: Maintained history in st.session_state.messages and passed past conversation turns to Groq's chat completion endpoint.

7. Conclusion & Future Enhancements

  • Conclusion: The College Enquiry Chatbot successfully automates admission FAQs with high accuracy, zero hallucinations, fast response times (under 1 second), and an intuitive UI.
  • Limitations: Currently relies on a single text file (college_info.txt); cannot ingest hundreds of unstructured PDF brochures dynamically.
  • Future Scope: Implement a full Retrieval-Augmented Generation (RAG) pipeline utilizing LangChain, ChromaDB/FAISS vector databases, and semantic search to index multi-page course prospectuses, faculty directories, and live ERP database feeds.
